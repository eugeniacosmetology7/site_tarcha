# Сайт Євгенії Тарча

Двомовний сайт: [словацька версія](https://evgenia-tarcha.com/sk/) — основна, [українська версія](https://evgenia-tarcha.com/uk/).

У репозиторії збережено готову статичну збірку в `diz/`. Вихідного коду Next.js немає. Vercel публікує `diz/` без збирання згідно з `vercel.json`.

Контент редагується через Sanity Studio (код у `studio/`). Ціни організовані за категоріями, кожна послуга має назву словацькою й українською, ціну та необов’язкову позначку. У документі «Тексти, контакти та фото» редагуються видимі тексти, контакти, головні фото, портфоліо й SEO-метадані. Опубліковані зміни сайт читає із Sanity під час відкриття сторінки; якщо API тимчасово недоступне, відображається збережена версія в `diz/`.

Адмінка: [evgenia-tarcha.sanity.studio](https://evgenia-tarcha.sanity.studio/). Для входу потрібен учасник Sanity-проєкту `Site`.

Початкові дані для порожнього Sanity проєкту створює `node studio/seed.mjs`. Їх уже завантажено в `production`. Повторний імпорт початкових даних після редагування в адмінці перезапише зміни замовника, тому його виконують лише один раз.

Інструкція з публікації: [DEPLOYMENT.md](DEPLOYMENT.md).
