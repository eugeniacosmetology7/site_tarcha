# Публікація сайту

Ця папка містить лише готову статичну збірку в `diz/`. Вихідного коду Next.js немає, тому для публікації не потрібно запускати `next build`.

## GitHub → Vercel → власний домен

1. Додати цю папку до GitHub-репозиторію.
2. Імпортувати репозиторій у Vercel. Кореневою папкою проєкту залишити корінь репозиторію. Налаштування в `vercel.json` обирають `Other`, пропускають збирання, публікують `diz/` та перенаправляють `/` на словацьку версію `/sk/`.
3. Додати власний домен у Vercel і налаштувати DNS за інструкціями Vercel для конкретного домену.
4. SEO-адреси вже налаштовані на `https://evgenia-tarcha.com` у `diz/robots.txt`, `diz/sitemap.xml` і метаданих обох мовних сторінок.
5. Після публікації перевірити `/`, `/sk/`, `/uk/`, `/robots.txt`, `/sitemap.xml` та кнопки контактів на власному домені.

Перенаправлення головної сторінки описано в `vercel.json`.
